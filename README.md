🚁 Overview

This project focuses on building an intelligent UAV (Unmanned Aerial Vehicle) Navigation System using Liquid Neural Networks (LNNs).
The goal is to enable drones to navigate dynamically changing environments such as wind disturbances, moving obstacles, and uncertain terrains with better adaptability than traditional neural networks.

Liquid Neural Networks are inspired by biological nervous systems and are known for:

Real-time adaptability
Lower computational requirements
Better decision-making in dynamic environments
Improved interpretability compared to deep black-box models

This project demonstrates how LNNs can be used for autonomous drone navigation and compares their performance with traditional neural network models.

✨ Features
Autonomous UAV navigation simulation
Real-time obstacle avoidance
Dynamic path adjustment
Wind disturbance adaptation
Comparison with traditional neural networks
Lightweight and efficient model
Visualization of drone movement
Training and evaluation pipeline

🧠 What is a Liquid Neural Network?

A Liquid Neural Network is a type of neural network where neurons continuously change their behavior based on incoming data over time.

Real-life Analogy

Imagine two drivers:

One driver follows fixed rules only.
Another driver continuously adapts based on traffic, weather, and road conditions.

Traditional neural networks are like the first driver.
Liquid Neural Networks behave like the second adaptive driver.

This makes LNNs very useful for:

Drones
Robotics
Self-driving cars
Real-time AI systems
